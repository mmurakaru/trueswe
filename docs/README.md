# Guide

TrueSWE runs reproducible coding tasks and compares project instructions or skills.
Start with [local setup](local-services.md), then choose a workflow:

- [Native agents](native-agents.md): select Codex, Claude Code, or Grok Build and configure authentication.
- [Task snapshots](task-snapshots.md): freeze a real issue, source commit, and independent verifier.
- [Instruction comparisons](instruction-comparisons.md): run baseline and candidate instructions against fixed inputs.
- [Managed skills](managed-skills.md): publish complete bundles and compare pinned versions.
- [Human review](human-review.md): inspect Jev suggestions and record evidence-linked decisions.
- [Resume](resume.md): recover an interrupted experiment without repeating completed work.

See the [specification](spec.md) for requirements, [releases](releases.md) for contribution and release checks, and [skill sources](skill-sources.md) for provenance.
